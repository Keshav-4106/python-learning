# Python Learning Journey

This repository is made for beginners who want to learn Python in a simple and practical way.

I am learning Python step by step and uploading my practice programs, notes, and concepts here with beginner-friendly comments and simple explanations.

Most explanations are written in an easy Hinglish style so students can understand concepts without feeling confused or overwhelmed.

## Topics Covered

* Variables
* Data Types
* Operators
* String Slicing
* Input/Output
* Practice Questions
* More coming soon...

## Goal

Learning Python should feel simple, practical, and beginner-friendly.

I started learning programming a little late, so I want to make learning easier for other beginners who are starting their journey.
